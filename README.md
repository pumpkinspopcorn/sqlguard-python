# SQLGuard for Python

A friendly security scanner that finds SQL injection bugs in Python source files and suggests safe fixes — no security expertise needed.

## Features
- Static analysis of Python .py files
- Taint tracking through variables
- AI-powered fix suggestions
- Visual dashboard with charts

## Run locally

pip install -r requirements.txt
python app.py

Then open http://localhost:5000 in your browser.
